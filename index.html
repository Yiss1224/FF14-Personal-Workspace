單職業快速估算

每日隨機 EXP 並不是固定數字：獎勵會依角色等級與抽到的內容變動，所以工具用比例做逐日／逐級模擬；之後可再加入你的個人實測校正。

多職業練等排程

每個 Daily 一天只能領一次，所以排程會真的把它分配給不同職業，而不是每個職業都各吃一套。上到下就是集中練模式的優先順序。

排程設定

同一等級的普通戰鬥職需要的升級 EXP 相同；真正會影響規劃的是目前等級/EXP、兵裝加成、一天有限的 Daily 分配，以及你願意額外刷幾本。角色欄與平均排隊時間會直接拿去算今晚時間成本。

副本 EXP 資料

副本階梯使用完整練等副本清單；Wiki 有 Base EXP 實值就採用，缺少的數字則明確標示估算。

尚未讀取副本 EXP

兵裝加成只套在副本本體 EXP：Lv1–89 +100%、Lv90–99 +50%（前提是該職業低於你最高戰鬥職）。Duty Roulette 的每日 Bonus 不吃兵裝加成。休息加成、食物與部隊效果目前先不算，ETA 會稍微保守。

今晚排程器

給一個今晚可玩的時間，它會把剩下的 Daily、排隊時間、額外刷本與排隊釣魚一起算進去，優先塞進比較值得的項目。

調整各 Daily 的平均時間 / 想打程度

本體時間不含排隊；排隊取職業列裡的「平均排隊 min」。想打程度 0–100 只影響平衡 / 混模式排序，不會改 EXP。

先選地圖或釣點，再自動顯示該範圍的魚餌／釣法。

「推薦餌」不等於「萬能餌一定不能用」。每隻魚可自行標成萬能餌可用／不可用／未確認；不可用與未確認才會進準備清單。取得方式按鈕會解析餌的 Item ID 後開 Teamcraft 資料頁。
